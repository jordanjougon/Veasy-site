Stack Next.js 16 + Tailwind CSS v4, 4 pages : homepage, /comment-ca-marche, /pvt-france, /telecharger. Déployé sur Vercel.

**Why:** Site marketing pour l'app Veasy (checklist + timing dossier Working Holiday Visa / PVT France).

**Cible actuelle :** Brésiliens uniquement. L'app ne supporte que la nationalité brésilienne pour le moment. Le formulaire d'inscription préremplit automatiquement "Brésil". D'autres pays seront ajoutés plus tard.

**Implication :** le site devrait idéalement être en portugais brésilien (pt-BR) pour capter le trafic SEO brésilien (`pvt França`, `visto working holiday França`, etc.). Actuellement en français — décision à prendre.

**How to apply:** Avant toute recommandation SEO ou contenu, rappeler que le marché cible est brésilien. Les keywords brésiliens (pt-BR) sont prioritaires sur les keywords français.
